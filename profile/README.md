# HUBIplan

**Freie, webbasierte Vereinsverwaltung für Vereine jeder Art, von 10 bis 10.000 Mitgliedern.**

HUBIplan ersetzt Excel-Listen, Papierordner und Zettelkasse durch eine gemeinsame Anwendung
im Browser und auf dem Telefon: Mitglieder, Beiträge und SEPA, Kasse nach GoBD, Termine,
Rundschreiben, Dokumente und die Vereinswebseite an einem Ort, mit klaren Rechten für
Vorstand, Untereinheiten und Mitglieder. Alle Funktionen sind allgemein gehalten und lassen
sich einzeln ein- und ausschalten. HUBIplan läuft auf dem eigenen Server des Vereins.

> **English:** HUBIplan is free (AGPL-3.0-or-later), self-hostable membership management for
> clubs and associations. It targets German clubs, so the user interface and documentation
> are in German. Issues and security reports in English are welcome.
